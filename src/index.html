📖 Blueprint Perencanaan & Knowledge Core

Ringkasan panduan arsitektur, standar taksonomi keahlian, formula algoritma pencocokan, serta kepatuhan hukum ketenagakerjaan dan perpajakan (PPh 21).

1. Blueprint Perencanaan (Ringkasan)

TemuTalenta mengadopsi prinsip Offline-First & Local-First Architecture. Sistem dapat beroperasi mandiri di browser tanpa server eksternal, memastikan demonstrasi, kurasi internal, dan pengujian berjalan cepat dan aman. 

Arsitektur:
[Browser UI (HTML5, Semantic)] <---> [Offline Engine (Scoring, LocalStorage, JSON Export)]
                                      |
                                      +--- (Fase Lanjutan: PWA & Sync Backend API)

Peta Jalan (*Roadmap*):

  • M1 (Saat Ini): Standalone Offline MVP dengan database talenta lokal, filter multi-kategori, dan simulasi matchmaking.
  • M2: Ekspor & impor profil JSON standar, manajemen bookmark, dan kalkulator kepatuhan pajak PPh 21 tenaga ahli.
  • M3: Dukungan Progressive Web App (PWA) dengan Service Worker untuk akses penuh saat tidak terkoneksi jaringan.
  • M4: Integrasi REST API & database terpusat (PostgreSQL) jika beralih ke mode cloud multi-tenant.

2. Knowledge Core (Formula Matchmaking & Standar)

Formula penilaian kesesuaian kandidat terhadap parameter kebutuhan:

Total Match Score = (0.45 * Skill) + (0.25 * Pengalaman) + (0.20 * Budget) + (0.10 * Ketersediaan)
Faktor Penilaian Bobot Metode Evaluasi
Keahlian (Skills) 45% Rasio perbandingan keahlian yang dimiliki kandidat terhadap syarat wajib.
Pengalaman (Experience) 25% Pencapaian batas minimum tahun pengalaman yang disyaratkan.
Kesesuaian Anggaran 20% Evaluasi rate ekspektasi talenta vs batas maksimal anggaran proyek.
Ketersediaan 10% Status kesiapan bergabung (Available Now = 100%, Open to Offers = 75%).

3. Kepatuhan Hukum & Pajak Indonesia

Platform mengadopsi standar perlakuan PPh 21 Tenaga Ahli Bukan Pegawai:

  • Dasar Pengenaan Pajak (DPP) = 50% × Penghasilan Bruto.
  • PPh 21 Terutang = Tarif Pasal 17 UU HPP × DPP.
  • Kerahasiaan data dan portofolio dilindungi sesuai UU Pelindungan Data Pribadi (UU No. 27/2022).
